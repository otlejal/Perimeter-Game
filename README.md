# Учебные игры по защите информации

Два браузерных прототипа по курсу «Защита информации в автоматизированных системах».
Каждый — один HTML-файл без сервера и интернета: открывается двойным кликом.

## «Периметр» — основная игра

`perimeter/index.html`

Tower defense про защиту сети, физического периметра и аппаратного уровня.
Атаки идут волнами, перед каждой волной видна разведка: тип угрозы, маршрут,
прочность и урон.

- 18 узлов: сеть (Интернет, Периметр, Веб, Ядро, АРМ, 1С/БД, Бэкап, Филиал,
  ИИ-сервис), физический контур (Улица, Офис, Серверная) и аппаратный стек
  (Прошивка, Загрузчик, Ядро ОС, PCIe/Thunderbolt, USB, Обновления).
- 17 типов атак: эксплойт, фишинг, подбор паролей, флешка, шифровальщик,
  проникновение, кража ноутбука, перехват канала, DDoS, утечка, подмена прошивки,
  bootkit, BadUSB, DMA, подписанный драйвер, закладка в оборудовании,
  закладка в ИИ-модели.
- 28 средств защиты в 8 категориях: сетевые, хостовые, доступ, данные,
  физические, аппаратные, организационные, ИИ.
- 30 волн: сеть и физика (1–18), аппаратный уровень (19–25), комбинации (26–30).
- Переключатель схемы «Сеть и объект» / «Аппаратный уровень».
- Бюджет, слоты на узлах, К/Ц/Д, ремонт между волнами, разбор после каждой волны.

Экономика: 80 ₽ на старте, 22 ₽ за волну (+10 за чистую), ремонт +15 К/Ц/Д
за 30 ₽. Урон атак растёт к финалу.

Как играть: выбрать узел → нажать карточку средства (откроется описание и
эффективность) → установить → «Начать волну».

## «Наследство админа» — прототип

`game/index.html` — детектив про обследование унаследованной АС: карта системы,
доска улик, связки и версии. `game/v1.html` — первая версия интерфейса.
